Redacted items

Hidden from every list and search, reachable by direct link only (#282). A redacted file is held on the NAS and never deleted unless you click "Delete file permanently". Recover it to put the file back, or delete it for good. Un-redact (only for rows whose file is already gone) just puts the row back in browsing.

Trash

Deleted items' files wait here 7 days so a delete can be undone, then they're removed for good. Redacted files are held separately, with no expiry: "Empty trash now" never touches them.
